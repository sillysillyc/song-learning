# 这是一个用于学习唱歌的项目
## 项目的分为3期
### 1期
#### 本期基础功能
1. 根据上传的歌词内容，将歌词分句展示
2. 提供标记歌词的功能，在标记歌词下面展示标记，长度由用户自己选择，长度为用户选择的歌词的字符所占的长度
3. 标记的颜色和符号、图形由用户自己选择

#### 详细说明
##### 1. 首页
1. 进入首页展示 Card 列表,Card 列表按修改时间倒序排列，最新修改的在最前面，Card 列表展示文件夹的名称、歌曲的数量、创建时间、最新编辑时间时间
2. 点击 Card, 打开右侧 Drawer 以 Table 展示文件夹内的列表，列表展示歌曲的名称、歌手、专辑、时长、创建时间、最新编辑时间；其中歌曲名称必填，其他为可选项列表最右侧操作按钮为查看、删除
3. 点击查看，进入歌曲详情页
4. 点击删除，Modal.confirm 二次确认，确认后移除这一首歌曲的标记数据
5. 首页顶部左右布局，左方有一个表单，用于本地搜索folder，有2个搜索框，第一个是搜索id，第二个是搜索名称，右侧有2个按钮，分别是搜索、重置；右方有2个按钮 编辑、新增
    1. 点击编辑，Card 列表变成可勾选状态，可以一次性移除多个folder及内部对应的歌曲数据，且右侧按钮变成 取消、确定，点击确定后，Modal confirm 二次确认，确认后重新展示列表且按钮变回编辑、新增
    2. 点击取消，Card 列表变成不可勾选状态，且右侧按钮变成 编辑、新增
    3. 点击新增，打开右侧 Drawer， 内部是一个表单，表单有以下必填项目：文件夹名称,底部2个按钮取消，确认
        1. 点击取消，关闭 Drawer
        2. 点击确认，确认后重新展示列表且按钮变回编辑、新增一条 folder 数据在列表最上方

##### 2. 歌曲详情页
歌词应该一个字或者一个英文单词作为一个元素来展示，方便选择标记的范围
1. 歌曲详情页分为sticky效果的内部header+上下布局
    1. 内部 header sticky 效果，且右侧有2个按钮 编辑、删除
        1. 点击编辑，页面进入编辑状态，标记可以编辑，内部header 的按钮变为 取消、保存
            1. 点击保存或者取消后都回到查看状态
        2. 点击Modal.confirm 二次确认，确认后移除这一首歌曲的标记数据，且跳转到上一首歌的详情也，如果没有上一首歌则回到首页
    2. 上方布局歌曲详情页展示歌曲的名称、歌手、专辑、时长、创建时间、最新编辑时间；其中歌曲名称必填，其他为可选项；
    3. 下方展示歌曲的歌词内容，及用户给指定歌词做的标记，标记的长度为用户选择的歌词的字符所占的长度，标记的颜色和符号、图形由用户自己选择
2. 编辑状态
    1. 歌曲信息：编辑状态可以编辑歌曲的名称、歌手、专辑、时长、创建时间、最新编辑时间；其中歌曲名称必填，其他为可选项；
    2. 歌词标记：编辑状态可以编辑歌词标记，包括标记的长度、颜色、符号、图形；
    3. 点击编辑后应该以左右分栏的形式展示左侧待编辑的歌词和右侧所有编辑工具，可以选择任意歌词长度进行标记，标记有这些：下划线（合成一拍）、自定义符号、自定义文本、自定义颜色等；
    4. 标记控制的范围和文本长度就是鼠标选择文本的长度，只控制选择的所有文字或者英文单词

其他
在浏览器上缓存的数据需要可导出为json的按钮选项，这样下次使用时可以导入直接使用，直接将导出按钮做成 FloatButton放在右下角，作为竖向悬浮工具栏中的一个按钮

### 2期
#### 1. 整体样式优化
1.1 不要整体滚动，顶部 header 固定
1.2 header 下的内容可以滚动

#### 2. 歌曲详情页
2.1 3 列 n 行展示歌词及对应的标记
2.2 sticky header 取消

#### 3. 歌词标记
不需要额外的保存一次标记，修改了对应的标记类型和内容修改之后就自动应用，只留取消和保存编辑按钮，点击这个按钮才保存，否则回退更改

3.1 标记的样式需要优化，圆标记应该是每个字都是圆背景
3.2 目前标记后文本的计算精度有问题，设置标记后可能有一两个未标记的文字被视为已经标记而且无法选择
3.3 注意歌词标记的数据结构是否足够健壮、可读、有拓展性，是否考虑使用对象将标记相关的属性一起存入
3.4 目前指定符号的渲染有点小问题
3.5 目前重复编辑已经选择的歌词和标记时未回显选择的歌词文本
